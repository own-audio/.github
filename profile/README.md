Your family's audiobooks, podcasts and music in one library, on every device
in the house.

- **[server](https://github.com/own-audio/server)**: the self-hosted server.
  Rust and PostgreSQL, a web console and an OpenSubsonic API. Free software
  under the AGPL-3.0-or-later. Pre-release.
- **Try it**: https://demo.own.audio, signed in as `guest@demo.own.audio`
  with the password `own-audio-demo`. It resets every night.
- **Images**: `ghcr.io/own-audio/server` and
  [`kornelko2/own-audio-server`](https://hub.docker.com/r/kornelko2/own-audio-server)
  on Docker Hub, for amd64 and arm64.

Native apps for Apple devices, Android and Windows are in development, and a
hosted service is coming at [own.audio](https://www.own.audio).

Contact: contact@own.audio
